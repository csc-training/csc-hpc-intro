# HPC Computing Environment

Welcome! This site contains self-learning materials for using the Roihu and LUMI supercomputers.

## How to use these materials

1. Topics are ordered by increasing complexity. The first part covers the
   basics. If you know them already, jump to the second part.
2. In each topic, first go through the slides.
3. Complete the tutorials to make sure you've got the steps right.
4. Try out the exercises to verify your new skills.
5. If you get stuck, consult [Docs CSC](https://docs.csc.fi), linked in the
   slides and the tutorials.
6. If the documentation doesn't answer your question, contact
   [CSC Service Desk](https://research.csc.fi/support) or email
   <servicedesk@csc.fi>. You can also
   [join our weekly user support coffee](https://ssl.eventilla.com/usersupportcoffee/EN)
   to discuss your issue with our specialists.
